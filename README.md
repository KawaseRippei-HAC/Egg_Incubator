# タマゴインキュベータ

![タマゴインキュベータ タイトル](Assets/Art/Images/ゲームタイトル画像.png)

## 制作時期とゲーム概要
2026/8/29,30 に開催されたサイバーエージェント様のインターン「プロトスプリントリーグ2026」で制作した、「スマートフォン向けバランスアクション」です。
スマートフォンを傾けてフライパンを操作し、暴れるタマゴを落とさずに孵化させる、縦持ちの1人用バランスアクションゲームです。

ただ耐えるだけでは孵化は進みません。フライパン上を移動する「スイートスポット」にタマゴを乗せ続けると孵化が進みますが、スポットは縁寄りへ動き、滞在中ほどタマゴも激しく暴れます。「安全を取るか、危険を承知で孵化を進めるか」という判断を短いプレイの中に組み込みました。

## 担当箇所 (自身の担当: 担当A)
主にタマゴの物理挙動とジャイロセンサーを利用した入力制御を実装しました。[cite: 1]

- **`Scripts/Input/EggController`**
  タマゴの基本物理挙動および、時間経過や難易度に応じて内部から暴れる処理を制御するスクリプトです。[cite: 1]速度や角速度に上限を設け、想定外の吹き飛びを防ぐ安全制御も実装しています。[cite: 1, 2]
- **`Scripts/Input/EggFallDetector`**
  タマゴがフライパンの判定外に出た（落下した）ことを検知するスクリプトです。落下時にカメラを追従させる演出のトリガーとしても機能します。[cite: 1, 2]
- **`Scripts/PanController/PanController`**
  スマートフォンのジャイロセンサー入力を取得し、フライパン（台）の回転・傾きへと直感的に変換するスクリプトです。[cite: 1]
- **`Scripts/GamePlay/EggFallDetector`**
  ゲームループ進行上における落下の判定を行い、ゲームオーバー（失敗）ステートへの移行を管理するスクリプトです。[cite: 1]

## アピールポイント・苦労した点

### アピールポイント
タマゴの挙動において、物理演算（Rigidbody）に完全に依存するのではなく、スクリプト制御（AddForce / AddTorque）を組み合わせることで、「予測不能すぎない範囲で暴れる」という制御された不規則さを実現しました。[cite: 1]また、ジャイロ入力値に感度や最大傾斜角、補間を設けることで細かい手ブレを防ぎ、プレイヤーの操作が直感的にタマゴの反応に繋がる手触りの良い操作性を構築できた点が技術的なアピールポイントです。[cite: 1]

### 苦労した点
- スマホ向けゲームを制作したのが初で、ジャイロ機能についての知識がなく実装について具体的なイメージができなかった点
  -> 事前の準備期間でジャイロ機能の実装についてUnityリファレンスやQiita等のブログを閲覧し、技術検証を行ったことにより2日間中の1日目での実装がかなった
- 事前想定よりも、実装をしてみたらたまごの暴れる動きが思ったより激しくなってしまい、理不尽にたまごが落ちてしまう問題が起きた点
  -> 微妙に中心へ向かう補正を入れることにより(`EggController`)、一回の動きで台の外に落ちないようにし、ユーザー自身のジャイロ操作でカバーできることが可能になった。
